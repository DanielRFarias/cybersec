# cybersec
Reminder and challenge of the course done about cybersecurity from DIO


Durante o curso da DIO sobre cybersegurança foi notado como o kali linux é excelente para testes relacionados ao assunto, bem como metasploitable deve apenas ser usado como s.o de teste.

A ferramenta mais utilizada foi medusa, mas também foram citadas outras, como mencionado a melhor ferramenta depende da situação, mas a medusa parece um bom ponto de partida e por bem ou por mal mais genérico.

Outra ferramenta usada tanto nessa aula como em anteriores foi o nmap, que serviu tanto individualmente como para auxiliar outras ferramentas.

A lista de usuários e senhas passadas foram bastante simples, servem para teste, mas para melhor análise é melhor buscar listas mais completas online.

A maior lição do curso acabou sendo que usuários são o maior fator de risco, parece simples, mas sempre é bom lembrar.
